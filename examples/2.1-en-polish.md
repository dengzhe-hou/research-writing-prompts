# 2.1 英文润色：最小改动示例

> 合成示例。输入是一段带语法错误和非母语表达的英文，输出只修必要的地方，不添加原文没有的结论。

## 输入

```latex
Nowadays, deep learning has been widely used in EEG decoding. However, the existing methods is hard to capture the long-range dependence, and also ignore the frequency information. In this paper, we propose a novel method, which is based on the multi-scale attention, to solve the above problems.
```

## 输出 Part 1（LaTeX）

```latex
Deep learning is widely used for EEG decoding. However, existing methods struggle to capture long-range dependencies and often ignore frequency information. We propose a multi-scale attention method that addresses both limitations.
```

## 输出 Part 2（中文直译）

```text
深度学习已广泛用于脑电解码。然而，现有方法难以捕捉长程依赖，并且常常忽略频率信息。我们提出一种多尺度注意力方法来解决这两个限制。
```

## 输出 Part 3（修改日志）

- 删除 `Nowadays`：学术段落不需要这种时间铺垫。
- `the existing methods is` → `existing methods struggle`：修正主谓一致，并把 `is hard to` 换成更直接的动词。
- `the long-range dependence` → `long-range dependencies`：可数名词用复数。
- `and also ignore` → `and often ignore`：保留原意，同时避免两个连接词叠加。
- `a novel method, which is based on ...` → `a multi-scale attention method`：去掉宣传性的 `novel` 和冗余定语从句。
- `to solve the above problems` → `that addresses both limitations`：明确回指前一句的两个问题。

## 可选的 diff 模式

在 Input 末尾加一行 `MODE: diff` 时，Part 1 可以只返回：

```diff
--- original
+++ revised
@@
-Nowadays, deep learning has been widely used in EEG decoding. However, the existing methods is hard to capture the long-range dependence, and also ignore the frequency information. In this paper, we propose a novel method, which is based on the multi-scale attention, to solve the above problems.
+Deep learning is widely used for EEG decoding. However, existing methods struggle to capture long-range dependencies and often ignore frequency information. We propose a multi-scale attention method that addresses both limitations.
```

## 核对清单

- [x] 没有新增实验、数据集、数字或引用。
- [x] `novel` 被删掉，而不是换成另一个更夸张的词。
- [x] 两个限制（长程依赖、频率信息）在改写后仍然一一对应。
- [x] 输出是完整段落，没有改成 item 列表。
