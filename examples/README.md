# Examples

These examples show the expected output shape and the checks a careful reader
should run. They use synthetic inputs; the numbers are not real results. They
are not a benchmark and do not rank the prompts.

- [1.1 Chinese → English](1.1-zh-en.md): LaTeX escaping, back-translation and
  what not to add.
- [2.1 English polish](2.1-en-polish.md): minimal edits and an optional unified
  diff.
- [5.1 Experiment analysis](5.1-results.md): every number traceable to the input
  table, no significance claim from a single run.

To propose a new example, follow `CONTRIBUTING.md`: synthetic input only, and
every number in the output must be reproducible from the input.
