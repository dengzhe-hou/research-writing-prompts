# 5.1 实验分析：数字必须对得上表

> 合成示例。表格和输出中的数字完全对应；不要把这个例子当成真实实验结果。

## 输入（实验结果表）

| Method | Accuracy (%) | Params (M) |
|---|---:|---:|
| Baseline A | 74.2 | 12.1 |
| Baseline B | 75.0 | 25.4 |
| Ours | 78.4 | 14.7 |
| Ours w/o cross-band attention | 76.1 | 13.9 |

补充信息：三个数据集上的平均值；Baseline B 是表中 strongest baseline；所有数字为单次运行。

## 输出 Part 1（LaTeX）

```latex
\paragraph{Accuracy Gains Without a Parameter Cost}
The proposed method reaches 78.4\% average accuracy, 3.4 percentage points above the strongest baseline (Baseline B, 75.0\%) and 4.2 points above Baseline A (74.2\%). This gain does not come from a larger model: our method uses 14.7M parameters, 42\% fewer than Baseline B's 25.4M.

\paragraph{Cross-Band Attention Accounts for Most of the Gain}
Removing the cross-band attention module lowers accuracy from 78.4\% to 76.1\%, a drop of 2.3 points, while reducing parameters by only 0.8M. The drop accounts for about two thirds of the 3.4-point margin over Baseline B, which is consistent with the module being the main source of the improvement. Because these are single-run results, we do not claim statistical significance.
```

## 输出 Part 2（中文直译）

```text
\paragraph{不增加参数量的精度提升}
所提方法达到 78.4% 的平均准确率，比最强基线（Baseline B，75.0%）高 3.4 个百分点，比 Baseline A（74.2%）高 4.2 个百分点。这一提升并非来自更大的模型：我们的方法使用 14.7M 参数，比 Baseline B 的 25.4M 少 42%。

\paragraph{跨频带注意力贡献了大部分提升}
移除跨频带注意力模块后，准确率从 78.4% 降到 76.1%，下降 2.3 个百分点，而参数量只减少 0.8M。这一降幅约占相对 Baseline B 的 3.4 个百分点优势的三分之二，说明该模块是提升的主要来源。由于是单次运行结果，我们不断言统计显著性。
```

## 核对清单

- [x] 78.4、75.0、74.2、76.1 与表格一致。
- [x] 3.4 = 78.4 − 75.0；4.2 = 78.4 − 74.2；2.3 = 78.4 − 76.1。
- [x] 42% = (25.4 − 14.7) / 25.4，按四舍五入写成 42%。
- [x] 0.8M = 14.7 − 13.9。
- [x] “约三分之二” = 2.3 / 3.4，没有写成精确的 67.6%。
- [x] 明确写了单次运行，没有声称统计显著性。
- [x] 没有补数据集名称、运行次数或置信区间，因为输入没有给。

## 常见失败

- 把 75.0 当成“最强基线”却同时说“比所有基线高 4.2”，两个参照系混用。
- 说“参数量减少 42%”却拿 14.7 和 12.1 比，参照错了。
- 把 2.3 个点的消融下降写成“证明该模块不可或缺”。
- 自行补“在三个数据集上均显著提升”，但输入没有逐数据集结果。
