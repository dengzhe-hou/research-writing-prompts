# 1.1 中译英：输入、输出与回译核对

> 合成示例，只演示输出格式和核对方式，不是效果基准。输入中的数字是虚构的。

## 输入（中文草稿）

```text
我们提出了一种基于多尺度时空注意力的脑电解码框架。该框架在三个公开数据集上进行了评估，平均准确率达到 78.4%，比最强基线高 3.1 个百分点。消融实验表明，跨频带注意力模块贡献了大部分提升。
```

## 输出 Part 1（LaTeX）

```latex
We present a multi-scale spatio-temporal attention framework for EEG decoding. We evaluate the framework on three public datasets, where it reaches 78.4\% average accuracy, 3.1 percentage points above the strongest baseline. Ablation experiments show that the cross-band attention module accounts for most of the improvement.
```

## 输出 Part 2（中文直译，用于核对）

```text
我们提出了一种用于脑电解码的多尺度时空注意力框架。我们在三个公开数据集上评估该框架，其平均准确率达到 78.4%，比最强基线高 3.1 个百分点。消融实验表明，跨频带注意力模块贡献了大部分提升。
```

## 核对清单

- [x] `%` 已转义为 `\%`。
- [x] 78.4 和 3.1 与输入一致，没有新增数字。
- [x] “三个公开数据集”保留，没有补数据集名称。
- [x] 没有把“贡献了大部分提升”升级为“显著提升”或给出具体百分比。
- [x] 回译能逐句对上原文，没有漏掉“消融实验”。

## 常见失败

- 输出 `78.4%` 而不是 `78.4\%`，LaTeX 编译报错。
- 把“最强基线”改写成具体方法名，但输入没有给。
- 自行补一句“代码和数据集将公开”，输入没有这个承诺。
